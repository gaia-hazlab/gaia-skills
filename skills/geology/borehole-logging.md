# Borehole Logging and Core Description

## Overview

Borehole logging is the systematic description of subsurface materials recovered during drilling or augering. It generates stratigraphic records of soil horizons, rock types, weathering profiles, and groundwater conditions. Standardised core logs are fundamental inputs to geological models, geotechnical designs, and hydro-geophysical interpretations.

## Prerequisites

- Familiarity with basic soil and rock classification schemes
- Access to field description standards (AGS, ISO 14688, ISO 14689, or USCS)
- Logging forms or digital logging software

## Key Concepts

- **Core recovery and RQD**: percentage of core recovered vs. drilled length; Rock Quality Designation counts intact pieces >10 cm.
- **Unified Soil Classification System (USCS)**: classifies soils by grain-size distribution and plasticity.
- **ISO 14688 / ISO 14689**: European standards for soil and rock description in geotechnical investigations.
- **Weathering grade**: I (fresh) to VI (residual soil); reflects degree of chemical and physical alteration.
- **Munsell colour notation**: standardised colour description used in both soil science and geology.

## Step-by-Step Workflow

1. **Prepare**: review site geology; gather logging forms, colour chart, sieves, and basic lab equipment.
2. **Lay out core**: arrange core boxes in order; label each box with borehole ID, depth interval, and recovery.
3. **Photograph**: photograph core/auger spoil under consistent lighting; include scale bar and depth label.
4. **Describe stratigraphy**: record depth to contacts, USCS/ISO class, colour, structure, moisture, consistency or strength, and notable features.
5. **Measure RQD** (rock cores): count intact pieces >10 cm; record total recovery and RQD per run.
6. **Sample and test**: collect disturbed and undisturbed samples; run basic in-situ tests (SPT, pocket penetrometer).
7. **Draw log**: produce standardised graphic log showing lithological column, sample locations, groundwater levels, and test results.
8. **Submit data**: export in AGS4 or equivalent; archive photographs with metadata.

## Common Pitfalls

- **Recovery bias**: incomplete core recovery introduces bias in stratigraphic interpretation — record and note losses.
- **Inconsistent description**: use standardised classification throughout; avoid colloquial terms.
- **Sample disturbance**: rotary drilling disturbs weak soils — use appropriate drilling method for formation.
- **Depth errors**: measure core accurately; account for core loss when assigning depth to features.

## Quality Checks

- Recovery ≥90% for competent rock; note and investigate intervals of low recovery.
- Independent check-logging of ≥10% of core by a second geologist.
- Verify sample depths match log entries.
- Check that AGS4 export validates against the format specification checker.
