# Security policy

Plugins here are instructions that AI agents act on. If you find a plugin that could make an
agent leak data or credentials, run a destructive command, or bypass a user's permission
settings, report it privately: use **Report a vulnerability** under this repository's
**Security** tab (GitHub private vulnerability reporting). Don't open a public issue or
discuss it in a pull request.

The maintainers aim to acknowledge a report within five working days.
